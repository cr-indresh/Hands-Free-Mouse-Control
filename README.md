# Hands-Free Mouse Control using Eye Tracking

## Overview
This project allows users to control the computer mouse using eye movements and blink detection.

## Features
- Real-time eye tracking
- Smooth cursor movement
- Blink-based mouse click
- Webcam support
- Beginner-friendly Python project

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

## Controls
- Press Q to quit the application

## Future Improvements
